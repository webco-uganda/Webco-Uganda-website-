# Deployment checklist

- [ ] Create Replit project and upload package
- [ ] `npm install`
- [ ] Set `SESSION_SECRET`
- [ ] Set `NODE_ENV=production`
- [ ] Run `npm start`
- [ ] Open `/admin` and create first admin
- [ ] Test membership application
- [ ] Test volunteer form
- [ ] Test contact form
- [ ] Add first project/news/event
- [ ] Configure domain
- [ ] Configure verified email
- [ ] Configure payment gateway before accepting real funds
- [ ] Add privacy policy and terms
- [ ] Configure database backups
