# WEBCO Website — Phase 1

This is the first static/public version of the WEBCO website.

## Files
- index.html — homepage
- about.html — organisation overview
- programmes.html — programme areas
- projects.html — project/future initiative overview
- membership.html — membership information + demo application form
- leadership.html — leadership profiles
- get-involved.html — join/volunteer/partner/support
- news.html — news/events placeholders
- contact.html — contact page + demo contact form
- css/style.css — shared design
- js/script.js — mobile menu + demo forms
- images/ — supplied leadership photographs

## How to use on a phone
1. Upload this folder/ZIP to a browser-based editor such as Replit.
2. Open `index.html` or configure the editor as a static site.
3. Replace the placeholder contact details and any text marked for confirmation.
4. Replace `images/hero-placeholder.svg` with an approved community/project photo when available.
5. Connect forms to a backend in Phase 2.

## Important
The membership, volunteer and contact forms are demo forms. They do not send/store data yet.
The next phase should add a database, secure authentication, admin controls and proper form handling.
